Tickets from a shell

Agents drive this board with ag ticket. No server and no token: it writes the same file the board reads, and signs with the session's name. Paste the snippet into a project's CLAUDE.md (or an agent's system prompt) so every agent knows the routine.

ag ticket list [--project here|PATH] [--status S] [--type T] [--assignee A] [--area NAME] [--mine] [--open] [--json]
ag ticket show ID
ag ticket new "Title" [--type bug|task|story|spike|chore] [--priority low|medium|high|urgent]
                      [--body TEXT | --body -] [--project PATH] [--area NAME] [--label L] [--due YYYY-MM-DD] [--take]
ag ticket take ID                   claim it: assigned to you, In progress
ag ticket move ID STATUS            backlog | todo | in_progress | review | done
ag ticket done ID                   finished
ag ticket assign ID NAME            hand it to someone ('none' unassigns)
ag ticket comment ID "text"         leave a note
ag ticket edit ID [--title ..] [--type ..] [--priority ..] [--body ..] [--label ..] [--area ..] [--due ..]
ag ticket prefix [NEW]              this project's prefix; with NEW, rename it and its tickets
ag ticket delete ID

Every command takes --as NAME and --json. Without --as, the name is $AGENTGRID_AGENT
(set for agents the board starts), else "claude"/"codex", else your login.
--project defaults to the git checkout the command runs in.
